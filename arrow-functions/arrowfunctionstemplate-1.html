Change this H1

The function changes the color of the h1 based on the color you pass into the function.

Named Function

            function changeColor(color){
                document.querySelector('h1').style.color = `${color}`;
            }
            changeColor('green');

Function Expression

            const changeColor = function(color){
                document.querySelector('h1').style.color = `${color}`;
            }
            changeColor('green');

Arrow Function

            const changeColor = (color) => document.querySelector('h1').style.color = `${color}`;
            changeColor('green');
